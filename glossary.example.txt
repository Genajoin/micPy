# Словарь терминов micPy: подсказка для Whisper, как писать английские слова.
# По одному термину на строку или через запятую. # — комментарий.
# Файл читается при каждой записи, перезапуск не нужен.
# Путь по умолчанию: ~/.config/micpy/glossary.txt (или MICPY_GLOSSARY).
#
# Размер: Whisper берёт в подсказку ~223 токена (≈ 50 терминов; латинский термин
# 2–4 токена, кириллическая аббревиатура 4–5). Сервер micPy при переполнении
# отбрасывает термины с конца и пишет в лог «prompt trimmed».
# Больше — не лучше: посторонние термины размывают подсказку (на тесте 16 точных
# терминов дали 31/41 попаданий, те же 16 среди 16–39 лишних — 25–28/41).
# Пишите то, что модель путает. Python, GitLab, PostgreSQL, React, Redis, Nginx,
# JSON, TypeScript Whisper пишет верно и без словаря.
# Русские IT-глаголы («закоммить», «задеплой») добавлять не нужно.
